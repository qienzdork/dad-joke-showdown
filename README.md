# Dad Joke Showdown

A program that writes exactly one original dad joke to `entry.txt` — a
straight-faced, dinner-table groaner with a clean pun and the punchline
right at the end.

Run it with:

```sh
python3 main.py
```

It writes the joke to `$OUTPUT_DIR/entry.txt` (default `/output`).
